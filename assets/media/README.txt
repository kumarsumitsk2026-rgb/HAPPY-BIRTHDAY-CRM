=== VOICE NOTE & MEDIA INSTRUCTIONS ===

To add a voice note for CRM AALI:
1. Record your voice note (audio message).
2. Save or convert it as an MP3 file.
3. Rename the file to: voice-note.mp3
4. Place it inside this folder: assets/media/voice-note.mp3

The website will automatically detect the file and display the sleek audio player inside the Gift Box!
If no file is placed here, the player automatically hides without any error or empty space.
